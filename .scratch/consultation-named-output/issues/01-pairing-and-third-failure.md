# 具名独立结果的历史配对与三次失败停用

Status: resolved

## 范围

修复 `function_call_output` 的错误配对拒绝，并在第三次累计失败后停用本线程的咨询。
本次不提交、发布、安装或重置真实失败计数。

## 原始错误

```text
Consultation failed: A tool result has no matching call.
Code: pairing
Details: {"stage": "item", "type": "function_call_output", "recordIndex": 234, "hostVersion": "0.167.0-alpha.4.1", "historyIndex": 108}
```

## 已验证原因

2026-11-17，本地可读的 Windows 原始记录
`/mnt/c/Users/Shy/.codex/sessions/2026/11/12/rollout-2026-11-12T10-48-11-01a1cda7-cf0a-72c3-9d66-5379f1afd8ec.jsonl`
在位置 234 和 235 包含两项宿主应用结果。两项类型都是 `function_call_output`，
命名空间为 `agent`，名称分别为 `codex_apps_open_page` 和
`codex_apps_selected_page_part_1_of_1`，没有 `call_id`，此前也没有同名调用。
原始记录在调用位置 240 通过生产 `reconstruct()` 复现上述全部诊断字段。

Codex CLI `0.169.0` 生成的协议允许 `function_call_output.call_id` 缺省或为
`null`，同时提供可选的 `name` 和 `namespace`。生产校验此前一律要求结果匹配调用。
重建没有丢失对应调用；此形状本身是独立结果。

停用代码此前使用 `FAILURE_LIMIT = 4`。当前要求是第三次累计失败后停用。

## 修改

- 策略表声明具名独立函数结果。仅在没有调用编号、名称为非空字符串、命名空间缺省、为空值或为字符串时接受。
- 保留独立结果的名称、命名空间、输出和顺序，并在真实请求中比较。独立结果不完成任何未决调用。
- 普通孤立结果、空调用编号、错误类型和未完成配对继续失败。
- 历史回放的未决调用跟踪复用生产判定。
- 第三次失败返回停用状态；成功不清零；后续调用在历史重建和原生执行前停止。
- 旧数据库计数四仍可读取并保持停用。中英文运行说明和各入口同步更新。
